## What the person wants (their own words)

When you move to a new country there's a mountain of paperwork — visa, bank
account, tax number, housing — and it's easy to lose track of what you've done
and what's next. I want an app where a newcomer lists the tasks they need to
sort out, with a note and a status (not started, in progress, done), and a due
date if there is one. Then a clear list of what's still outstanding. It's
personal and sensitive, so it must be strictly private to the person. A short
AI explainer that, given a task like "open a bank account", lists the usual
steps would really help people who don't know where to start.

## Complete when

- I can sign in with an emailed code and only see my own tasks.
- I can add a settlement task (title, note, status, optional due date) and it saves.
- After a restart, my tasks are still there with the same values.
- A task can be edited (including its status) and deleted.
- Another signed-in person cannot see, change, or delete my tasks.
- There is an "outstanding" list showing tasks that are not done, from saved data.
- The AI "explain the usual steps for this task" feature returns a readable answer.
- Every screen shows what the server saved.
