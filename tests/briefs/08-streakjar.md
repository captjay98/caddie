## What the person wants (their own words)

I want to build better habits — drink water, read, stretch. I want a simple app
where I list the habits I'm trying to keep, and each day I tick off the ones I
did. I want to see my streak for each habit, so how many days in a row I've kept
it up. Just mine, saved so I don't lose it. Nothing complicated.

## Complete when

- I can sign in with an emailed code and only see my own habits.
- I can add a habit (name) and it saves.
- Each day I can mark a habit done, and untick it; that is saved.
- After a restart, my habits and their marks are still there.
- A habit can be renamed and deleted.
- Another signed-in person cannot see, change, or delete my habits.
- Each habit shows a current streak computed from saved marks.
- Every screen shows what the server saved.
