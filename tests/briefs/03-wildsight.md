## What the person wants (their own words)

I volunteer for a local nature group and we want to keep a shared log of
wildlife we spot — the species, roughly where, the date, and a count. I want to
add a sighting, and I want the group to be able to add theirs too, so we build
up one picture of what's around. Then a simple page that counts how many of each
species we've logged this month. It should be mine and the group's — random
members of the public shouldn't be editing our records.

## Complete when

- I can sign in with an emailed code.
- I can create a conservation group and invite the other volunteers to it.
- Any group member can add a sighting (species, place, date, count) and it saves.
- After a restart, every sighting is still there with the same values.
- A sighting can be edited and deleted by group members.
- Someone who isn't in the group cannot see, add, change, or delete its sightings.
- There is a page that counts sightings per species for the current month, from
  saved data.
- Every screen shows what the server saved.
