# Delivery-checklist skill (P05 v1)

Prepare verifiable delivery artifacts from real receipts.

## Discipline

- Derive the checklist from the project's actual requirements, never a
  universal template. Missing video/repo/license stays missing.
- Every artifact cites its receipt: command, exit code, artifact hash.
- Demo and live integrations are labelled distinctly; never present a demo as
  live.
- The human presses Submit. Prepare; never submit.
